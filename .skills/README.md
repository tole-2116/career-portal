# 🛠️ Project Skills & Development Guidelines

Thư mục `.skills/` chứa các hướng dẫn kỹ năng nội bộ cho dự án **Career Portal**, giúp các thành viên nhóm và AI agent hiểu rõ quy chuẩn, quy trình và kiến trúc của dự án.

---

## Danh sách hướng dẫn

| File | Nội dung |
| :--- | :--- |
| [git-workflow.md](./git-workflow.md) | Quy ước nhánh, commit message, quy trình PR & merge |
| [code-style.md](./code-style.md) | Kiến trúc dự án, quy chuẩn code, tạo route, i18n & stores |
| [testing-and-build.md](./testing-and-build.md) | Các lệnh kiểm tra chất lượng, typecheck, lint, build |

---

## Cách sử dụng

- **Nhóm phát triển:** Đọc trước khi bắt đầu làm việc với dự án để đảm bảo nhất quán.
- **AI Agent:** Tham chiếu các file này như context khi được yêu cầu thực hiện thay đổi trên codebase.
- **Người mới:** Bắt đầu từ file `git-workflow.md` để hiểu quy trình làm việc, sau đó đọc `code-style.md` để nắm kiến trúc.

---

> **Lưu ý:** Các hướng dẫn trong thư mục này được thiết kế bổ sung cho `SETUP_GUIDE.md` ở thư mục gốc. Nếu có xung đột, ưu tiên nội dung trong `SETUP_GUIDE.md`.
